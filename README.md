# Weather-aware free slots

A reusable Hermes skill for finding an outdoor break from free time and live hourly forecasts. It also contains an offline example with a known 30-minute result.

```sh
hermes skills tap add Chao1iu/weather-aware-slots
hermes skills install Chao1iu/weather-aware-slots/skills/weather-aware-slots
```

Run `python scripts/weather_slots.py --example` from the installed skill directory. [Skill instructions and input format](skills/weather-aware-slots/SKILL.md)
